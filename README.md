🚀 QuickDrop — فایل بفرست، با یه لینک بره!
سرویس اشتراک‌گذاری فایل بدون ثبت‌نام — فایل آپلود کن، لینک بگیر، بفرست.کاملاً رایگان و بدون سرور، اجرا روی زیرساخت Cloudflare.
