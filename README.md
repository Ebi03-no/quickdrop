# 🚀 QuickDrop — فایل بفرست، با یه لینک بره!

سرویس اشتراک‌گذاری فایل بدون ثبت‌نام — فایل آپلود کن، لینک بگیر، بفرست.
کاملاً رایگان و بدون سرور، اجرا روی زیرساخت Cloudflare.

## ❤️ امکانات و محافظت

| قابلیت | توضیح |
|--------|-------|
| 🕵️ بدون ثبت‌نام | نه ایمیل می‌خواد، نه اکانت، نه لاگین |
| 🖼️ پیش‌نمایش زنده | عکس‌ها قبل از آپلود thumbnail می‌گیرن |
| 🎬 آیکون هوشمند | هر نوع فایل آیکون خودشو داره (ویدیو، موزیک، PDF و...) |
| 📊 پیشرفت واقعی | نوار درصد آپلود زنده + پیام‌های بامزه |
| 🔗 لینک فوری | به‌محض اتمام آپلود، لینک آماده‌ست |
| 📱 QR Code | خودکار ساخته میشه — اسکن کن، دانلود کن |
| ✈️ اشتراک مستقیم | دکمه ارسال سریع به تلگرام و واتساپ |
| 📥 صفحه دانلود اختصاصی | اسم، حجم و نوع فایل قبل از دانلود مشخصه |
| 🚫 بدون تبلیغ | نه تایمر، نه کپچا، نه انتظار |

## 🎨 ظاهر و تجربه کاربری

| قابلیت | توضیح |
|--------|-------|
| 🌅 تم تیره سینمایی | پالت گرم نارنجی/مرجانی/بنفش با شفق‌های شناور |
| 🪟 گلس‌مورفیسم | کارت شیشه‌ای با حاشیه گرادیانی متحرک |
| 💡 نورافکن موس | کارت اصلی نور دنبال‌کننده موس داره |
| 🎉 کانفتی جشن | بعد از هر آپلود موفق منفجر میشه! |
| 📱 واکنش‌گرا | از موبایل تا دسکتاپ |
| 🇮🇷 فارسی و RTL | با فونت وزیرمتن |

## ⚙️ فنی

| قابلیت | توضیح |
|--------|-------|
| ☁️ بدون سرور | ۱۰۰٪ روی Cloudflare Workers اجرا میشه |
| 🌍 سرعت جهانی | اجرا روی +۳۰۰ دیتاسنتر کلادفلر |
| 💾 ذخیره‌سازی | بدون دیتابیس — فقط Cloudflare KV |
| 🔓 پهنای باند رایگان | دانلود نامحدود، بدون هزینه egress |
| 📦 بدون build | فرانت‌اند تک‌فایل HTML |
